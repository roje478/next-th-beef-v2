Getting Started

Prerequisites

Before you begin, ensure you have the following installed:

  • Node.js v18 or later
  • pnpm package manager (recommended) or npm

Installation

Follow these steps to set up your project:

  1. Unzip the package and open the project folder in your code editor.
  2. Open a terminal in the root of the project folder.
  3. Install dependencies: 
    pnpm install
  4. Start the development server: 
    pnpm dev

Your site is now running at http://localhost:4000.

Available Scripts

Command Description
pnpm dev Start development server on port 4000
pnpm build Create optimized production build
pnpm start Start production server
pnpm lint Run ESLint checks
pnpm lint:fix Auto-fix ESLint issues

Customization

Changing Images

All images are in public/, organized by content type (e.g., public/hero/, public/menu/, public/team/). Replace files with your own, keeping the same filename for a quick update. If you use a new filename, update the path in the corresponding data file inside src/app/hooks/.

Managing Content

All template content is centralized in the src/app/hooks/ directory. Each file manages data for a specific part of the site, making content updates simple and predictable.

File Content
data-hero.tsx Hero sections (titles, descriptions, images)
data-dish.tsx Menu dishes (names, prices, descriptions)
data-team.tsx Chef/team member profiles
data-blog.tsx Blog posts, categories, tags
data-gallery.tsx Gallery images
data.tsx General site data (inner page heroes, etc.)

Example from data-dish.tsx:

export const menuWeekData = {
    subtitle: "This week's specials",
    title: "Delicious Dishes You Can't Miss",
    items: [
        {
            id: 1,
            title: "pan seared scallops",
            price: "$29.00",
            description: "Saffron, celeriac puree...",
        },
        // ... more items
    ],
};

Simply edit the values in these files to change the site's content. All changes are reflected automatically.

Colors & Fonts

The design tokens are configured in tailwind.config.ts. The project uses two main color scales:

  • calico — Gold/bronze accent colors (buttons, highlights, decorative elements)
  • coarseWool — Dark background shades (surfaces, cards, sections)

Four Google Fonts are loaded via next/font in src/app/layout.tsx:

  • Josefin Sans — Navigation, subtitles
  • Barlow Condensed — Headings, titles
  • Sorts Mill Goudy — Decorative text, numbers
  • Mulish — Body text, labels

Adding New Pages

  1. Create a new folder inside src/app/(routes)/
  2. Add a page.tsx file with your component
  3. Add a metadata export for SEO
  4. Next.js will automatically create the route
// src/app/(routes)/reservations/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
    title: "Reservations",
    description: "Book your table online.",
};

export default function ReservationsPage() {
    return <div>Your content here</div>;
}
// Available at: /reservations

Deployment

Building for Production

Create an optimized production build:

pnpm build

The output will be located in the .next directory. All pages are statically generated for maximum performance.

Deploy to Vercel (Recommended)

The easiest way to deploy a Next.js application is with Vercel:

  1. Push your project code to a Git repository (GitHub, GitLab, or Bitbucket).
  2. Sign up for a Vercel account and connect your Git provider.
  3. Import your repository — Vercel auto-detects Next.js.
  4. Click "Deploy". Your site will be live in minutes.

Future pushes to your main branch will trigger automatic redeployments.

Self-Hosting

To host the application on your own server:

# Build the project
pnpm build

# Start the production server
pnpm start

Use a process manager like pm2 to keep your application running:

pm2 start "pnpm start" --name beef-restaurant
